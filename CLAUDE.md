# CLAUDE.md — FitCoach Bot

Памятка для Claude Code. Продукт — [PROJECT_IDEA.md](PROJECT_IDEA.md).
Техническая спецификация (архитектура, БД, LLM, деплой) — [docs/TECH_SPEC.md](docs/TECH_SPEC.md).

## Суть проекта
Telegram-бот — личный фитнес-ассистент. Помогает наладить питание и сбросить лишние килограммы:
- недельный план питания с разными рецептами и подсчётом КБЖУ;
- план тренировок 3 раза в неделю (тренажёрный зал и дом) с акцентом на укрепление тела;
- отслеживание прогресса (вес, замеры, выполненные тренировки, калории).

Основной пользователь — владелец проекта (один человек). Мультипользовательность — позже.

## Этапы (делаем строго по порядку)
1. **MVP: консультант по питанию** — анкета, расчёт нормы КБЖУ, недельное меню с рецептами, список покупок.
2. **Тренировки** — программы для зала и дома, 3 раза в неделю, прогрессия нагрузок.
3. **Трекинг прогресса** — дневник веса/замеров/тренировок, графики, напоминания, корректировка плана.

Не начинай работу над следующим этапом, пока текущий не закрыт и не протестирован.

## Стек
- Python 3.12+
- aiogram 3.x (асинхронный Telegram Bot API, FSM для анкет)
- SQLAlchemy 2.x async + Alembic; PostgreSQL/asyncpg в проде, SQLite/aiosqlite локально и в тестах
- Claude API: SDK `anthropic`, модель `claude-opus-5-5`, `messages.parse()` + pydantic-схемы
- pydantic-settings (`.env`), APScheduler и matplotlib (этап 3), pytest + pytest-asyncio, ruff

## Инфраструктура
- Репозиторий: https://github.com/Kris30-max/telegram-botik1 (ветка `main` = production)
- Хостинг: Railway — сервис `bot` (Dockerfile; настройки сервиса — в UI Railway) + плагин Postgres.
  Push в `main` → GitHub Actions (ruff + pytest) → Railway автодеплой (Wait for CI).
- Миграции — `alembic upgrade head` в CMD контейнера перед стартом бота (config-as-code Railway недоступен). Long polling, **ровно 1 реплика**.
- Секреты только в Railway Variables / локальном `.env`. Никогда не коммитить токены.

## Ключевые правила разработки
- **КБЖУ считает код, а не LLM.** Норма калорий — формула Миффлина-Сан Жеора × коэффициент
  активности, дефицит 15–20% (не больше 500 ккал/сут). КБЖУ рецепта — сумма ингредиентов
  из справочника продуктов (значения на 100 г). LLM только предлагает блюда и ингредиенты.
- Ответы LLM запрашиваем в структурированном виде (JSON по схеме) и валидируем pydantic.
  Невалидный ответ → повторный запрос, не показываем пользователю «сырой» текст.
- Допуск расхождения КБЖУ дня с целью: ±5% по калориям; иначе пересобрать/скорректировать порции.
- Тренировочные планы строятся из проверенного справочника упражнений и шаблонов программ
  (full body 3×/нед), LLM не выдумывает упражнения.
- Каждая тренировка: разминка → основная часть → заминка; указаны подходы, повторы, отдых, RPE.
- Везде дисклеймер: бот не заменяет врача; при болях/заболеваниях — консультация специалиста.
- Переменные: `BOT_TOKEN`, `ANTHROPIC_API_KEY`, `DATABASE_URL`, `ALLOWED_USER_IDS` (полный список — TECH_SPEC §4).
- LLM: всегда проверять `stop_reason` (refusal), не передавать `thinking`, effort через `output_config`.
- Вся пользовательская текстовка — на русском языке. Код, имена переменных — на английском.
- Хендлеры тонкие: логика — в `services/`, работа с БД — в `db/`.
- Типизация везде (type hints), форматирование `ruff format`, линтер `ruff check`.

## Команды
```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
alembic upgrade head          # миграции
python -m bot.main            # запуск бота
pytest                        # тесты
ruff check .; ruff format .   # линт и форматирование
```

## Тестирование
- Обязательно unit-тесты для расчёта КБЖУ, нормы калорий и сборки меню.
- LLM в тестах мокать; проверять валидацию и обработку кривых ответов.
- Перед завершением задачи: `pytest` и `ruff check .` должны проходить.

## Риски, о которых помнить
- Ошибки в подсчёте калорий → только детерминированный расчёт + тесты.
- Неверные/нереалистичные рецепты → валидация ингредиентов по справочнику, разумные порции.
- Небезопасный тренировочный план → шаблоны уровня опытного тренера, прогрессия, техника, отдых.
