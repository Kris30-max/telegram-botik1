# FitCoach Bot — описание проекта

Telegram-бот — личный фитнес-ассистент, который помогает наладить питание, тренироваться
по продуманной программе и видеть свой прогресс.

---

## 1. Проблема

- **Неправильное питание.** Нет системы: питаюсь хаотично, не знаю, сколько калорий
  на самом деле съедаю, сколько нужно белков, жиров и углеводов.
- **Не получается сбросить лишние пару килограмм.** Без понимания своей нормы калорий
  и без дефицита вес стоит на месте.
- **Однообразие и нехватка времени.** Придумывать каждый день, что приготовить и как
  уложиться в калории, — долго и надоедает, поэтому срываюсь на «что попало».
- **Нет плана тренировок.** Непонятно, что делать в зале и дома, как распределить нагрузку,
  как прогрессировать и не травмироваться.
- **Не вижу прогресса.** Без записей сложно понять, работает ли то, что я делаю, и мотивация падает.

---

## 2. Решение

Бот в Telegram, который всегда под рукой и закрывает три задачи:

### 2.1. Питание
- Анкета: пол, возраст, рост, вес, уровень активности, цель (снижение веса), ограничения
  и нелюбимые продукты, количество приёмов пищи, бюджет/время на готовку.
- Расчёт **индивидуальной нормы КБЖУ**:
  - базовый обмен по формуле **Миффлина-Сан Жеора**:
    - мужчины: `10 × вес(кг) + 6.25 × рост(см) − 5 × возраст + 5`
    - женщины: `10 × вес(кг) + 6.25 × рост(см) − 5 × возраст − 161`
  - × коэффициент активности (1.2 / 1.375 / 1.55 / 1.725);
  - дефицит 15–20% для мягкого снижения веса (≈0.5 кг в неделю, не больше 500 ккал/сут);
  - белок 1.6–2.0 г/кг, жиры 0.8–1.0 г/кг, остальное — углеводы.
- **План питания на неделю**: 7 дней, разные блюда, без повторов подряд, 3–5 приёмов пищи.
- **Рецепты** к каждому блюду: ингредиенты в граммах, шаги приготовления, время, КБЖУ порции.
- **Список покупок** на неделю, сгруппированный по отделам магазина.
- **Замена блюда** одной кнопкой с сохранением КБЖУ дня.
- **Вопросы по питанию** в свободной форме («можно ли есть после 18:00?», «чем заменить сахар?»).

### 2.2. Тренировки
- **3 тренировки в неделю** (например, Пн/Ср/Пт) с акцентом на укрепление всего тела.
- Два режима: **тренажёрный зал** и **дома** (с собственным весом / гантелями / резинками),
  можно комбинировать.
- Структура каждой тренировки: разминка (5–10 мин) → основная часть → заминка и растяжка.
- Для каждого упражнения: подходы, повторения, вес/усилие (RPE), отдых, техника и типичные ошибки.
- **Прогрессия нагрузки** по неделям (повторы → вес → подходы), разгрузочная неделя раз в 4–6 недель.
- Учёт уровня подготовки (новичок/средний) и ограничений (больная спина, колени и т.п.).

### 2.3. Прогресс
- Дневник: вес, замеры (талия, бёдра, грудь), фото по желанию, выполненные тренировки, рабочие веса.
- Графики веса и замеров, недельные сводки.
- Напоминания: взвешивание, тренировка, приём пищи.
- **Автокорректировка плана**: если вес стоит 2–3 недели — пересчёт калорий;
  если упражнения даются легко — повышение нагрузки.

## 3. Как это выглядит для пользователя

**Первый запуск**
1. `/start` → приветствие, дисклеймер (бот не заменяет врача).
2. Анкета кнопками: пол → возраст → рост → вес → активность → цель → ограничения.
3. Бот показывает норму: «Ваша норма: 1850 ккал, Б 140 / Ж 60 / У 185».
4. Кнопка «Составить меню на неделю».

**Обычный день**
- Утром: «Доброе утро! Сегодня: завтрак — овсянка с ягодами (420 ккал) …» + кнопки
  «Рецепт», «Заменить блюдо».
- В день тренировки: «Сегодня тренировка B (дом), 45 минут» + кнопка «Начать».
- Вечером: «Как прошёл день? Отметить тренировку / записать вес».

**Раз в неделю**
- Сводка: изменение веса, выполнено тренировок 3/3, средние калории.
- Предложение составить меню на следующую неделю и обновлённую программу.

## 4. Архитектура

### 4.1. Стек
| Компонент         | Технология                                  |
|-------------------|---------------------------------------------|
| Язык              | Python 3.12+                                |
| Telegram          | aiogram 3.x (async, FSM, роутеры)           |
| БД                | SQLite (старт) → PostgreSQL (прод)          |
| ORM / миграции    | SQLAlchemy 2.x async + Alembic              |
| ИИ                | Claude API (Anthropic SDK)                  |
| Конфигурация      | pydantic-settings, `.env`                   |
| Планировщик       | APScheduler                                 |
| Графики           | matplotlib                                  |
| Тесты / качество  | pytest, pytest-asyncio, ruff                |
| Деплой            | Docker на VPS (polling → webhook позже)     |

### 4.2. Разделение ответственности
- **Код (детерминированно):** норма калорий, КБЖУ блюд и дня, масштабирование порций,
  список покупок, прогрессия нагрузки, статистика.
- **LLM (творческая часть):** подбор блюд и вариативность меню, текст рецептов,
  ответы на свободные вопросы, мотивационные комментарии.
- **Справочники:** продукты с КБЖУ на 100 г (основа — открытые таблицы калорийности),
  упражнения с описанием техники, шаблоны тренировочных программ.

### 4.3. Поток генерации меню
1. Код считает целевые КБЖУ на день.
2. LLM получает цель, ограничения и список доступных продуктов → возвращает JSON:
   блюда, ингредиенты, граммовки, шаги.
3. Код валидирует JSON (pydantic), сверяет ингредиенты со справочником,
   пересчитывает КБЖУ сам.
4. Если расхождение с целью > 5% — масштабирует порции; если не получается — перегенерация.
5. Результат сохраняется в БД и показывается пользователю.

### 4.4. Модель данных (черновик)
- `users` — telegram_id, имя, пол, возраст, рост, активность, цель, ограничения, уровень.
- `nutrition_targets` — дата расчёта, ккал, белки, жиры, углеводы.
- `products` — название, ккал/Б/Ж/У на 100 г, категория.
- `recipes` — название, шаги, время, порции; `recipe_ingredients` — продукт, граммы.
- `meal_plans` / `meal_plan_items` — неделя, день, приём пищи, рецепт, порция.
- `exercises` — название, группа мышц, оборудование (зал/дом), техника, противопоказания.
- `workout_programs` / `workout_sessions` / `workout_sets` — программа, тренировка, подходы.
- `body_logs` — дата, вес, талия, бёдра, грудь.
- `workout_logs` — дата, тренировка, выполнено, рабочие веса, самочувствие.

## 6. Риски и как их снижаем

| Риск | Последствия | Меры |
|------|-------------|------|
| **Неправильный подсчёт калорий** | Нет результата или вред здоровью | КБЖУ считает только код по справочнику; LLM цифры не придумывает; unit-тесты; ручная сверка с известными таблицами; дефицит не более 20% и не ниже базового обмена |
| **Неверные или нереалистичные рецепты** | Невкусно, несъедобно, не те КБЖУ | Ингредиенты только из справочника; проверка граммовок на адекватность (например, масло ≤ 30 г на порцию); структурированный JSON + валидация; кнопка «пожаловаться на рецепт»; база проверенных рецептов растёт со временем |
| **Непродуманный тренировочный план** | Травмы, отсутствие прогресса, потеря мотивации | Программы на основе проверенных шаблонов (full body 3×/нед), а не свободной генерации; обязательные разминка и заминка; баланс «толкающие/тянущие/ноги/кор»; прогрессия и разгрузка; объём по уровню; описание техники и ошибок; учёт противопоказаний; чек-лист «как у тренера с многолетним опытом» перед релизом |
| **Галлюцинации LLM** | Ложные советы | Строгие промпты, ограничение тематики, структурированный вывод, повторная генерация при ошибке |
| **Медицинские вопросы** | Ответственность, вред | Дисклеймер; при упоминании болезней, болей, беременности — рекомендация к врачу |
| **Стоимость API** | Расходы | Кэширование меню и рецептов, генерация раз в неделю, лимиты на `/ask` |
| **Потеря мотивации** | Брошенный проект | Мягкие напоминания, недельные сводки, маленькие победы |
| **Безопасность данных** | Утечка личных данных | Секреты в `.env`, минимум персональных данных, бэкапы БД |

### Чек-лист качества тренировочной программы
- Каждая мышечная группа прорабатывается 2–3 раза в неделю.
- Баланс движений: присед, тяга (наклон), горизонтальный/вертикальный жим, горизонтальная/вертикальная тяга, кор.
- 48 часов отдыха между тренировками на одни мышцы.
- Новичку: 2–3 подхода по 8–15 повторений, RPE 6–8, без работы «до отказа».
- Длительность тренировки 45–75 минут.
- Есть альтернатива каждому упражнению (дома ↔ зал, при ограничениях).

---

## 7. Метрики успеха
- Снижение веса на 0.3–0.7 кг в неделю без потери самочувствия.
- Выполнено ≥ 80% запланированных тренировок.
- Расхождение калорий меню с целью ≤ 5%.
- Цель первого цикла: минус 3–5 кг за 2–3 месяца.

---

## 8. Дисклеймер
Бот — помощник, а не врач и не диетолог. Рекомендации общие. При наличии заболеваний,
травм, беременности или приёме лекарств перед изменением питания и нагрузки нужна консультация специалиста.
